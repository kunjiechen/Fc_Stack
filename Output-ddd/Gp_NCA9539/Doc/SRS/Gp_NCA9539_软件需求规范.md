## 4 概述

### 4.1 外设芯片介绍

NCA9539-Q1 是纳芯微（Novosense）出品的 16 位 I2C 总线 GPIO 扩展器，通过 I2C 接口提供 16 个通用 I/O 引脚扩展能力，适用于汽车电子、工业自动化等场景。芯片通过 AEC-Q100 Grade 1 认证，工作温度范围 -40°C 至 125°C。

芯片支持以下功能：

- 16 位 GPIO 扩展（两个 8 位端口：端口 0 的 P00~P07，端口 1 的 P10~P17）
- 每引脚独立方向配置（输入/输出）
- 输入端口电平读取
- 输出端口电平控制
- 输入极性反转
- 开漏中断输出（INT\），在输入状态变化时触发
- 低有效硬件复位输入（RESET\）
- 内部上电复位
- 两个硬件地址引脚（A0, A1），支持最多 4 个器件共用同一 I2C 总线
- I2C Fast-mode（最高 400 kHz）
- 电源电压范围 1.65V ~ 3.6V，I/O 引脚 5V 耐压

### 4.2 驱动功能介绍

`Gp_NCA9539` 驱动应实现以下软件功能：

- 模块初始化与芯片上电/复位后的默认状态验证
- 通过 I2C 总线对芯片 8 个寄存器进行读写访问
- GPIO 引脚方向配置（输入/输出，每引脚独立）
- GPIO 输出电平控制（每引脚独立置高/置低）
- GPIO 输入电平读取（每引脚独立），支持极性反转后的值
- 开漏中断输出监控与响应
- 硬件复位控制与复位后的寄存器恢复
- 多器件实例管理（基于 A0/A1 地址区分，最多 4 个实例）
- 开发错误检测（DET）：非法参数、未初始化访问、通信故障等

### 4.3 外设引脚介绍

| 引脚 | 方向 | Pin口功能 |
| --- | --- | --- |
| INT\ | Output (芯片→MCU) | 开漏中断输出，输入状态变化时拉低 |
| A1 | Input (MCU→芯片) | I2C 地址位 1，接 VDD 或 GND |
| RESET\ | Input (MCU→芯片) | 低有效硬件复位 |
| P00~P07 | Bidir | 端口 0 GPIO，上电默认输入 |
| VSS | Power | 地 |
| P10~P17 | Bidir | 端口 1 GPIO，上电默认输入 |
| A0 | Input (MCU→芯片) | I2C 地址位 0，接 VDD 或 GND |
| SCL | Input (MCU→芯片) | I2C 串行时钟，需外部上拉 |
| SDA | Bidir | I2C 串行数据，开漏，需外部上拉 |
| VDD | Power | 供电电压 (1.65V~3.6V) |

### 4.4 状态机介绍

> NCA9539-Q1 不涉及复杂的软件模式状态机。芯片在 VDD 上电且 RESET\ 为高时处于正常运行状态；RESET\ 拉低或 VDD 低于 POR 阈值时处于复位状态。软件层面仅需关注初始化后的正常运行和复位恢复两种场景。

| 状态 | 说明 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| 未初始化 | 模块尚未完成初始化 | 系统启动后模块加载 | 初始化流程完成 |
| 正常运行 | 模块已初始化，可执行所有 GPIO 操作 | 初始化成功 | 复位事件或模块去初始化 |
| 复位恢复 | 芯片发生复位，寄存器回到默认值 | 检测到 RESET\ 或 POR 事件 | 重新初始化完成 |

### 4.5 通信参数

关键通信参数：

- 通信速率：支持 I2C Standard-mode (100 kHz) 和 Fast-mode (400 kHz)
- 器件寻址：7 位 I2C 地址，固定部分 11101b，可编程部分 A1 A0，支持 0x74/0x75/0x76/0x77 四个地址

| t_SU;DAT | 250 | — | 100 | — | ns |
| t_LOW | 4.7 | — | 1.3 | — | us |
| t_HIGH | 4.0 | — | 0.6 | — | us |

## 5 功能需求

本章描述模块必须实现的功能行为，包括模式与状态、接口、配置、诊断和错误处理。每条需求使用固定字段描述，以便后续生成设计、测试和追溯矩阵。

### 5.1 模式需求

#### SRS-Gp_NCA9539-FUNC-0001 模块初始化与复位恢复

`功能需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-POR; Datasheet-RESET pin`

`Gp_NCA9539` 模块应在上电或外部复位释放后，对指定实例执行初始化流程：验证 I2C 通信可达、确认芯片寄存器处于上电默认值、将端口配置为目标方向并设置输出端口初值。

**功能约束**

- **范围边界**：仅覆盖芯片寄存器初始化和默认值验证；不覆盖 MCU I2C 外设初始化和引脚映射配置。
- **前置条件**：VDD 已稳定在 1.65V~3.6V；RESET\ 引脚为高电平；MCU I2C 外设已初始化。
- **触发条件**：上层调用模块初始化接口并传入有效实例标识。
- **输入**：实例标识（区分不同 I2C 地址的芯片实例），端口方向配置，输出端口初值，极性反转配置。
- **输出**：初始化结果（E_OK / E_NOT_OK）；初始化后的芯片寄存器状态（Configuration/Output/Polarity 与目标配置一致）。
- **异常处理**：I2C 通信失败时返回 E_NOT_OK；寄存器默认值校验失败时返回 E_NOT_OK；实例已初始化时拒绝重复初始化并返回 E_NOT_OK。
- **验收准则**：上电后调用初始化接口返回 E_OK，且回读 Configuration 和 Output 寄存器与目标值一致。

#### SRS-Gp_NCA9539-FUNC-0002 多实例管理

`功能需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-A0/A1 addressing`

`Gp_NCA9539` 模块应支持最多 4 个芯片实例的独立管理，每个实例通过 A0/A1 地址引脚区分（I2C 地址 0x74/0x75/0x76/0x77）。各实例的初始化、配置、读写操作和中断处理应相互独立。

**功能约束**

- **范围边界**：实例数量上限由硬件地址引脚组合决定（2^2=4）；具体项目中使用的实例数量由配置决定。
- **前置条件**：各实例的硬件地址引脚已正确配置；I2C 总线上无地址冲突。
- **触发条件**：上层以不同实例标识调用模块接口。
- **输入**：实例标识（0~3，对应 I2C 地址 0x74~0x77）。
- **输出**：针对指定实例的 GPIO 操作结果。
- **异常处理**：实例标识超出配置范围时返回 E_NOT_OK；指定实例未初始化时返回 E_NOT_OK。
- **验收准则**：两个不同地址的芯片实例的 GPIO 操作互不影响。

### 5.2 接口需求

#### SRS-Gp_NCA9539-INTF-0001 GPIO 输出控制接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-Output Port Registers; Datasheet-Configuration Registers`

`Gp_NCA9539` 模块应提供接口允许上层对指定实例的指定端口引脚设置输出电平。模块应通过 I2C 将目标值写入对应的 Output Port 寄存器（端口 0: 地址 0x02，端口 1: 地址 0x03），且仅对已配置为输出方向的引脚生效。

**功能约束**

- **范围边界**：输出控制仅对当前已配置为输出的引脚生效；不支持自动将引脚从输入切换为输出。
- **前置条件**：目标实例已完成初始化；目标引脚已通过 Configuration 寄存器配置为输出。
- **触发条件**：上层调用输出控制接口，传入实例标识、端口标识和引脚电平值。
- **输入**：实例标识、端口号（0 或 1）、8 位输出值（bit=0 输出 LOW，bit=1 输出 HIGH）。
- **输出**：接口返回值（E_OK / E_NOT_OK）；芯片对应端口输出引脚电平更新。
- **异常处理**：实例未初始化时返回 E_NOT_OK 并保持原输出不变；端口号无效时返回 E_NOT_OK；I2C 通信失败时返回 E_NOT_OK 并保持原输出不变。
- **验收准则**：对已配置为输出的引脚写入目标值后，引脚电平与写入值一致；读回 Output Port 寄存器值与写入值一致。

#### SRS-Gp_NCA9539-INTF-0002 GPIO 输入读取接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-Input Port Registers`

`Gp_NCA9539` 模块应提供接口允许上层读取指定实例的指定端口的输入引脚电平。模块应通过 I2C 读取 Input Port 寄存器（端口 0: 地址 0x00，端口 1: 地址 0x01），并根据 Polarity Inversion 寄存器配置决定是否反转读取结果。

**功能约束**

- **范围边界**：读取值反映引脚实际电平（受极性反转影响）；无论引脚配置为输入还是输出，Input Port 寄存器均反映实际电平。
- **前置条件**：目标实例已完成初始化。
- **触发条件**：上层调用输入读取接口，传入实例标识和端口标识。
- **输入**：实例标识、端口号（0 或 1）。
- **输出**：接口返回值（E_OK / E_NOT_OK）；8 位输入端口值（极性反转后的逻辑值）。
- **异常处理**：实例未初始化时返回 E_NOT_OK 且输出指针内容不变；端口号无效时返回 E_NOT_OK；I2C 通信失败时返回 E_NOT_OK 且输出指针内容不变；输出指针为 NULL 时上报 DET 并返回 E_NOT_OK。
- **验收准则**：对指定端口引脚施加已知电平后，读取值与期望值一致（考虑极性反转配置）。

#### SRS-Gp_NCA9539-INTF-0003 GPIO 方向配置接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-Configuration Registers; Datasheet-I/O port`

`Gp_NCA9539` 模块应提供接口允许上层配置指定实例的指定端口各引脚方向。模块应通过 I2C 将配置值写入 Configuration 寄存器（端口 0: 地址 0x06，端口 1: 地址 0x07）。bit=1 对应输入（高阻态），bit=0 对应输出。

**功能约束**

- **范围边界**：方向配置可独立作用于每个引脚；引脚从输出切换为输入时可能触发假中断。
- **前置条件**：目标实例已完成初始化。
- **触发条件**：上层调用方向配置接口，传入实例标识、端口标识和方向配置值。
- **输入**：实例标识、端口号（0 或 1）、8 位方向配置值（1=输入，0=输出）。
- **输出**：接口返回值（E_OK / E_NOT_OK）；芯片对应 Configuration 寄存器更新。
- **异常处理**：实例未初始化时返回 E_NOT_OK；端口号无效时返回 E_NOT_OK；I2C 通信失败时返回 E_NOT_OK 并保持原配置不变。
- **验收准则**：写入方向配置后回读 Configuration 寄存器值一致；配置为输入的引脚呈高阻态，配置为输出的引脚受 Output Port 寄存器控制。

#### SRS-Gp_NCA9539-INTF-0004 极性反转配置接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-Polarity Inversion Registers`

`Gp_NCA9539` 模块应提供接口允许上层配置指定实例的指定端口的输入极性反转。模块应通过 I2C 将配置值写入 Polarity Inversion 寄存器（端口 0: 地址 0x04，端口 1: 地址 0x05）。bit=1 反转对应引脚输入值的极性，bit=0 保留原始极性。

**功能约束**

- **范围边界**：极性反转仅影响 Input Port 寄存器的读取值，不影响引脚实际电平；不影响 Output Port 寄存器。
- **前置条件**：目标实例已完成初始化。
- **触发条件**：上层调用极性反转配置接口，传入实例标识、端口标识和反转配置值。
- **输入**：实例标识、端口号（0 或 1）、8 位极性反转配置值（1=反转，0=不反转）。
- **输出**：接口返回值（E_OK / E_NOT_OK）；芯片对应 Polarity Inversion 寄存器更新。
- **异常处理**：实例未初始化时返回 E_NOT_OK；端口号无效时返回 E_NOT_OK；I2C 通信失败时返回 E_NOT_OK 并保持原配置不变。
- **验收准则**：配置极性反转后，读取 Input Port 寄存器值与引脚实际电平相反；未配置极性反转的引脚读取值等于实际电平。

#### SRS-Gp_NCA9539-INTF-0005 I2C 寄存器读写接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-I2C Interface; Datasheet-Bus Transactions`

`Gp_NCA9539` 模块应在内部封装对 NCA9539-Q1 芯片寄存器的 I2C 读写操作。写操作：发送 START → 器件地址(W) → 命令字节 → 数据字节(s) → STOP。读操作：发送 START → 器件地址(W) → 命令字节 → 重复 START → 器件地址(R) → 读取数据字节(s) → NACK → STOP。读写支持寄存器对内交替操作。

**功能约束**

- **范围边界**：仅封装芯片寄存器的 I2C 访问序列，不包含 I2C 总线驱动层实现。
- **前置条件**：MCU I2C 外设已初始化；目标实例的 I2C 地址已根据 A0/A1 确定。
- **触发条件**：上层或其他模块内部函数调用寄存器读写。
- **输入**：实例标识、寄存器地址（0x00~0x07）、写入数据指针及长度。
- **输出**：读取数据及长度；操作结果（E_OK / E_NOT_OK）。
- **异常处理**：I2C 总线仲裁丢失时重试或返回 E_NOT_OK；从机 NACK 时返回 E_NOT_OK；寄存器地址超出 0x07 时上报 DET 并返回 E_NOT_OK。
- **验收准则**：写入 Output Port 寄存器后回读值一致；读取 Input Port 寄存器值与引脚实际电平一致。

#### SRS-Gp_NCA9539-INTF-0006 中断状态读取接口

`接口需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-INT output; Datasheet-Interrupt`

`Gp_NCA9539` 模块应提供接口允许上层查询指定实例的中断状态，包括当前 INT\ 引脚电平及发生变化的输入端口标识。模块应在 Input Port 读取操作后自动清除对应端口的中断。

**功能约束**

- **范围边界**：中断检测基于芯片 INT\ 引脚状态，不覆盖 MCU 端 GPIO 中断控制器的配置；每个 8 位端口的中断独立清除。
- **前置条件**：目标实例已完成初始化；INT\ 引脚已连接至 MCU 并配置为输入。
- **触发条件**：上层调用中断状态查询接口；或中断服务例程触发。
- **输入**：实例标识。
- **输出**：中断状态（有效/无效）、触发中断的端口标识（端口 0/端口 1/两者）。
- **异常处理**：实例未初始化时返回 E_NOT_OK；INT\ 引脚未配置时记录诊断信息。
- **验收准则**：改变某输入引脚电平后，INT\ 有效且中断状态接口返回正确的触发端口；读取对应端口 Input Port 寄存器后中断清除。

### 5.3 配置需求

#### SRS-Gp_NCA9539-CFG-0001 实例数量与 I2C 地址配置

`配置需求` `ASIL-B` `Review / Review` `Draft` `来源: Datasheet-A0/A1; Datasheet-Device Address`

`Gp_NCA9539` 模块应支持通过编译期配置指定启用的实例数量及每个实例的 I2C 基地址。有效实例数量范围为 1~4。每个实例应关联唯一的 I2C 7 位地址（0x74、0x75、0x76 或 0x77）。

**功能约束**

- **范围边界**：I2C 地址仅在模块内部使用；实例数量受 A0/A1 硬件地址引脚组合限制。
- **前置条件**：硬件 A0/A1 引脚连接与配置的 I2C 地址一致。
- **输入**：配置项：实例数量、各实例 I2C 地址。
- **输出**：编译后的模块行为限制（仅允许访问已配置实例）。
- **验收准则**：配置 2 个实例（0x74、0x76）时，访问 0x75 地址返回实例无效错误；配置 4 个实例时全部地址可正常访问。

#### SRS-Gp_NCA9539-CFG-0002 I2C 通信速率配置

`配置需求` `QM` `Review / Review` `Draft` `来源: Datasheet-Dynamic Characteristics`

`Gp_NCA9539` 模块应支持 Standard-mode (最高 100 kHz) 和 Fast-mode (最高 400 kHz) I2C 通信速率配置。配置值应在模块初始化时生效并应用于所有实例。

**功能约束**

- **范围边界**：实际通信速率受 MCU I2C 外设和总线电容限制；模块仅传递速率参数给 I2C 驱动层。
- **前置条件**：MCU I2C 外设支持所配置的速率。
- **输入**：配置项：I2C 速率模式（Standard / Fast）。
- **输出**：I2C 通信速率配置生效。
- **验收准则**：配置 Fast-mode 后，SCL 频率不高于 400 kHz；配置 Standard-mode 后，SCL 频率不高于 100 kHz。

#### SRS-Gp_NCA9539-CFG-0003 上电默认引脚方向配置

`配置需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-Power-On Reset; Datasheet-Configuration Registers`

`Gp_NCA9539` 模块应在初始化时将各引脚的方向配置为目标值。若项目未指定某引脚方向，模块应以芯片上电默认值（输入/高阻态）作为初始方向。初始化完成后，模块应验证 Configuration 寄存器值符合预期。

**功能约束**

- **范围边界**：仅覆盖初始化阶段的方向配置；运行中方向变更由接口需求 SRS-Gp_NCA9539-INTF-0003 覆盖。
- **前置条件**：芯片已完成 POR 且 RESET\ 为高。
- **输入**：配置项：各引脚的目标方向（输入/输出）。
- **输出**：Configuration 寄存器值匹配目标方向配置。
- **异常处理**：回读 Configuration 值不匹配时返回 E_NOT_OK。
- **验收准则**：初始化后回读 Configuration 寄存器与目标配置一致；未指定方向的引脚保持默认输入状态。

### 5.4 诊断需求

#### SRS-Gp_NCA9539-DIAG-0001 DET 错误报告

`诊断需求` `ASIL-B` `Test / UT` `Draft` `来源: 项目需求-ASIL-B; Datasheet-I2C Interface`

`Gp_NCA9539` 模块应在以下条件发生时向 DET 模块报告开发错误：传入实例标识超出配置范围；在实例未初始化时调用需要初始化的接口；传入无效的端口号（非 0/1）；传入 NULL 指针参数；传入无效的寄存器地址（超出 0x00~0x07）。

**功能约束**

- **范围边界**：DET 报告遵循 AUTOSAR DET 规范；仅报告开发错误，不覆盖运行时的 I2C 通信故障。
- **前置条件**：DET 模块已启用。
- **触发条件**：接口调用时参数校验失败。
- **输入**：接口调用参数。
- **输出**：DET 错误报告；接口返回 E_NOT_OK。
- **验收准则**：传入非法参数时 DET 报告产生且接口返回 E_NOT_OK；传入合法参数时不产生 DET 报告。

#### SRS-Gp_NCA9539-DIAG-0002 I2C 通信故障诊断

`诊断需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-I2C Interface; Datasheet-Acknowledge`

`Gp_NCA9539` 模块应在 I2C 通信过程中检测从机 NACK 响应，并在发生 NACK 时记录通信故障状态。模块应提供接口供上层查询最近一次通信故障信息（故障实例、故障寄存器地址、故障类型）。

**功能约束**

- **范围边界**：仅检测 I2C 从机 NACK；不覆盖 I2C 总线仲裁丢失、SCL/SDA 短路等物理层故障。
- **前置条件**：目标实例已完成初始化。
- **触发条件**：I2C 写/读操作中从机返回 NACK。
- **输入**：I2C 通信 ACK/NACK 状态。
- **输出**：通信故障状态及故障详情（实例、寄存器地址、故障类型）；接口返回 E_NOT_OK。
- **验收准则**：断开 SDA 连接后发起寄存器读取，模块返回 E_NOT_OK 且记录通信故障。

#### SRS-Gp_NCA9539-DIAG-0003 中断状态丢失诊断

`诊断需求` `ASIL-B` `Test / UT` `Draft` `来源: Datasheet-INT output; Datasheet-Interrupt clearing`

`Gp_NCA9539` 模块应提供机制防止中断状态丢失：在 INT\ 有效期间，模块应记录触发中断的端口；在输入端口读取操作完成前，模块不得丢弃未处理的中断信息。当两个端口同时触发中断时，模块应分别记录各自的中断状态。

**功能约束**

- **范围边界**：仅保证软件层面不丢失已检测到的中断信息；不覆盖 INT\ 引脚边沿未被 MCU 捕获的硬件丢失场景。
- **前置条件**：目标实例已完成初始化；INT\ 引脚监控已使能。
- **触发条件**：INT\ 引脚有效（低电平）。
- **输入**：INT\ 引脚电平；输入端口寄存器值。
- **输出**：中断状态记录（实例、触发端口、时间戳或序列号）。
- **异常处理**：中断处理过程中发生新的输入变化，需保留或合并中断状态。
- **验收准则**：快速连续改变端口 0 和端口 1 的输入电平后，中断处理能记录两个端口均发生了中断。

## 6 非功能需求

### 6.1 时序需求

#### SRS-Gp_NCA9539-TIM-0001 复位释放后初始化等待时间

`时序需求` `ASIL-B` `Analysis / UT` `Draft` `来源: Datasheet-t_rec(rst); Datasheet-t_rst`

`Gp_NCA9539` 模块在释放 RESET\ 引脚后的初始化流程中，应在 RESET\ 释放后等待至少 200 ns（t_rec(rst)）再发起 I2C 通信。

**功能约束**

- **范围边界**：等待时间由模块内部实现，取不小于芯片手册 t_rec(rst) 最小值 200ns 的安全裕量。
- **触发条件**：RESET\ 引脚从低电平变为高电平。
- **验收准则**：复位释放后示波器测量 SCL 第一个时钟边沿距离 RESET\ 上升沿 >= 200 ns。

#### SRS-Gp_NCA9539-TIM-0002 RESET\ 脉冲宽度控制

`时序需求` `ASIL-B` `Analysis / UT` `Draft` `来源: Datasheet-t_w(rst)`

`Gp_NCA9539` 模块在通过 RESET\ 引脚复位芯片时，应保持 RESET\ 至少 6 ns 的低电平脉宽。

**功能约束**

- **范围边界**：模块应使用不小于 6 ns 的脉冲宽度，实际取值考虑 MCU GPIO 驱动能力和 PCB 走线延迟裕量。
- **触发条件**：上层调用复位接口。
- **验收准则**：示波器测量 RESET\ 低电平持续时间 >= 6 ns。

#### SRS-Gp_NCA9539-TIM-0003 输出端口稳定时间

`时序需求` `ASIL-B` `Analysis / UT` `Draft` `来源: Datasheet-t_v(Q)`

`Gp_NCA9539` 模块在写入 Output Port 寄存器后，若后续需读取输出引脚的实际电平，应在写操作完成后等待至少 300 ns（t_v(Q) 最大值）再执行读取操作。

**功能约束**

- **范围边界**：等待时间仅当软件需要确认输出已生效时使用；正常输出控制流不需要显式等待。
- **触发条件**：执行 Output Port 寄存器写操作后需要读回验证。
- **验收准则**：写操作后等待 >= 300 ns 再读回 Output Port 寄存器，读回值与写入值一致。

#### SRS-Gp_NCA9539-TIM-0004 中断响应时间约束

`时序需求` `ASIL-B` `Analysis / UT` `Draft` `来源: Datasheet-t_v(INT_N); Datasheet-t_rst(INT_N)`

`Gp_NCA9539` 模块在检测到 INT\ 有效（低电平）后，应在 4 us（t_v(INT_N) 最大值）内完成中断状态识别并启动对应的 Input Port 读取操作。读取完成后，INT\ 应在 4 us（t_rst(INT_N) 最大值）内释放（恢复高电平）。

**功能约束**

- **范围边界**：4 us 为芯片特性参数，软件中断响应延迟受 MCU 中断延迟和 I2C 通信速率影响；本需求的 4 us 为芯片侧参数约束，软件需在架构设计阶段给出整体中断延迟预算。
- **触发条件**：输入引脚电平变化导致 INT\ 拉低。
- **验收准则**：示波器测量 Input Port 读操作的 ACK 后 INT\ 恢复高电平的时间 <= 4 us（芯片侧）。

- **验收准则**：故意修改 Configuration 寄存器值后，模块检测到不一致并记录故障。

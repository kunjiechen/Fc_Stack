## A3. 工作模式

| 模式名 | 进入方式 | 退出方式 | 该模式下可用功能 | 上电默认 |
|--------|---------|---------|----------------|---------|
| 正常运行模式 (Operating) | 上电后 VDD >= V_POR | 掉电(VDD < V_PORF)或RESET拉低 | 全部I2C通信、GPIO输入/输出、中断检测 | 是 |
| 复位状态 (Reset) | RESET\引脚拉低或POR触发 | RESET\释放且VDD >= V_PORR | 无，寄存器和I2C状态机保持默认值 | — |
| 待机模式 (Standby) | SCL=0 kHz且无I2C活动 | I2C START条件 | 仅GPIO输入状态保持，中断检测保持 | — |

## A5. I2C 帧协议

| 字段 | 值 |
|------|-----|
| 帧位宽 | 8 bit |
| 命令结构 | 器件地址(7bit) + R/W(1bit) + 命令字节(8bit) |
| 响应结构 | ACK后紧跟数据字节(8bit)，MSB优先 |
| 地址空间范围 | 0x00 ~ 0x07 (8个寄存器) |
| Burst Read | 支持，读同一寄存器对内的另一个寄存器(port 0↔port 1交替)，无长度限制 |
| Burst Write | 支持，写同一寄存器对内的另一个寄存器(port 0↔port 1交替)，无长度限制 |
| CRC | 无 |
| 帧间最小 CS 高电平 | 不适用(I2C无CS) |
| 器件地址 | 固定部分 11101b，可编程部分 A1 A0，7位地址: 0x74/0x75/0x76/0x77 |

## A6. 中断资源

| 中断源名 | 触发条件 | 标志位 | 清除机制 | 是否可屏蔽 |
|----------|---------|--------|---------|-----------|
| INT\ | 任意输入引脚电平变化（上升沿或下降沿） | 无独立标志位 | 读产生中断的端口寄存器（ACK后清除）或端口电平恢复原值 | 不可屏蔽 |

## A7. 时钟与复位

| 字段 | 值 |
|------|-----|
| 时钟源 | I2C总线时钟(SCL)，由主控提供 |
| 复位源列表 | POR (内部上电复位), RESET\ 引脚(外部低有效) |
| 各复位源影响范围 | 全量复位：所有寄存器恢复默认值，I2C状态机初始化 |
| 复位后默认模式 | 正常运行模式，所有端口配置为输入(高阻态) |
| 复位恢复时间 | RESET\释放后 >= 200ns (t_rec(rst)) 可接受通信 |

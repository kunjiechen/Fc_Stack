# SRS 规则与模板

说明:

* 《Template-xxx 原始开发需求.md》,原始开发需求文档文档用于收集原始开发需求，一般为第三方需求的整理、上层应用对模块的需求或者软件负责人口述表达的需求收录。
* 《Template-FC模块软件需求规范.md》,软件需求规范是FC开发的标准完整需求，所有相关的需求都在此文档体现，代码的实现、测试验证都必须满足需求，且需要保证一致性追溯关系。
* 《FC需求编写规范.md》,用于规范 FC 软件需求的编写原则、编号规则、需求属性、质量标准和 SDD 输入要求。
* 《FC需求编写生成工作流.md》,用于指导从输入资料到 SRS 文档、追溯矩阵和评审结论的生成流程。
* 《Checklist/》,存放 SRS 各门禁点检查清单，用于输入完整性、来源追溯、内容完整性、需求质量、SDD 输入充分性和基线发布检查。

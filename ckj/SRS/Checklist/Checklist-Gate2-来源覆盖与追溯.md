# Gate 2 来源覆盖与追溯检查清单

## 1 检查目标

确认所有有效来源均已被处理，所有 SRS 需求均可回溯到明确来源，避免遗漏输入或生成无来源需求。

## 2 适用阶段

来源内容抽取完成后、SRS 初稿生成后、SRS 评审前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| 来源未处理 | 补充抽取、生成需求、说明 N/A 或登记开放项 |
| SRS 无来源 | 删除需求、补充来源或转开放项 |
| 推导过度 | 缩减需求范围，保持与来源一致 |
| 来源冲突 | 登记冲突开放项，等待责任方确认 |
| 追溯矩阵缺失 | 不允许进入 SRS Gate，必须补齐 |

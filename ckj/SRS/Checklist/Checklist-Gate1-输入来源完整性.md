# Gate 1 输入来源完整性检查清单

## 1 检查目标

确认 FC SRS 生成前所需输入资料已完整识别、归档、编号和适用性判断，避免在输入不完整的情况下生成需求。

## 2 适用阶段

SRS 编写启动前、来源内容抽取前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| 缺少关键输入 | 暂停确定性需求生成，补充输入或登记开放项 |
| 输入适用性不清 | 标记待确认，不得作为确定需求来源 |
| 来源定位不具体 | 补充章节、页码、标题或段落定位 |
| 版本冲突 | 登记冲突项，由责任方确认有效版本 |
| 安全输入缺失 | ASIL 不得默认，登记待安全确认开放项 |

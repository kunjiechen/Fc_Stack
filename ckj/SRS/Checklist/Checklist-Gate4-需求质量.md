# Gate 4 需求质量检查清单

## 1 检查目标

确认每条 SRS 需求正确、清晰、单一、可验证、可实现、可维护、可追溯，且未混入设计实现细节或无来源扩展。

## 2 适用阶段

SRS 初稿完成后、SRS Gate 评审前。

## 5 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| 多行为混写 | 拆分为多条需求 |
| 不可验证 | 重写为可观察行为或改为约束/开放项 |
| 模糊表达 | 改为枚举、范围、状态语义或明确条件 |
| 实现细节过多 | 删除内部实现描述，保留外部行为和约束 |
| 状态语义不清 | 明确软件请求、软件记录、硬件确认或不可确认 |
| 无来源扩展 | 删除、补来源或转开放项 |
| 需求矛盾 | 追溯来源，确认优先级后修正或登记冲突开放项 |

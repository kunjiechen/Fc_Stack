# Gate 5 SDD 输入充分性检查清单

## 1 检查目标

确认 SRS 已为软件架构设计（SDD）提供足够、明确、可追溯的输入，避免 SDD 阶段自行补充未定义的软件行为。

## 2 适用阶段

SRS 质量检查完成后、进入 SDD 阶段前。

## 4 下游不可接受情形

存在以下情形时，不建议进入 SDD：

- 对外接口能力不明确。
- 状态/模式集合不明确。
- 配置项范围和无效配置行为不明确。
- 错误类别和失败后置条件不明确。
- 安全等级或安全机制来源不明确。
- 硬件状态是否可确认不明确。
- SDD 需要自行假设关键行为才能继续设计。
- 高影响开放项未关闭且未获得评审批准。

## 5 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| SDD 输入缺失 | 回到 SRS 补充需求或登记开放项 |
| 接口语义不清 | 补充接口需求、API 清单或 IRS 输入 |
| 状态语义不清 | 补充模式/状态表和状态读取语义 |
| 配置边界不清 | 补充配置需求和无效配置处理 |
| 安全输入不清 | 登记安全开放项，不允许 SDD 自行默认 |
| Open 项阻塞 SDD | 关闭 Open 项或评审批准遗留风险 |

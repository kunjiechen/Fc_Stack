# Gate 6 SRS 基线发布检查清单

## 1 检查目标

确认 SRS 文档、追溯、开放项、评审问题和遗留风险均已达到基线发布条件，允许作为 SDD 阶段正式输入。

## 2 适用阶段

SRS 评审结束前、SRS 基线发布前、进入 SDD 前。

## 4 基线发布判定

| 判定 | 条件 |
| --- | --- |
| 通过 | 所有门禁通过，无阻塞开放项，无未批准 TBD，允许进入 SDD |
| 有条件通过 | 存在低影响遗留项，已评审批准，不阻塞 SDD |
| 不通过 | 存在无来源需求、关键输入缺失、高影响 Open 项未关闭、SDD 输入不足或评审问题未闭环 |

## 5 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| 任一前置 Gate 未通过 | 回到对应 Gate 修正问题 |
| 高影响 Open 项未关闭 | 补充输入、确认责任方，关闭或获得批准遗留 |
| 未批准 TBD | 删除、关闭、转正式 Open 项或评审批准 |
| 追溯不同步 | 更新 Trace 和附录需求清单 |
| SDD 输入不足 | 回到 SRS 补充需求，不允许 SDD 自行假设 |
| 评审问题未闭环 | 关闭问题或记录批准遗留风险 |

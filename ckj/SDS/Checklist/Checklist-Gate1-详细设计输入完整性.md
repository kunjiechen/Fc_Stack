# Gate 1 详细设计输入完整性检查清单

## 1 检查目标

确认 SDS 编写所需输入已完整收集、适用性明确、版本和章节可追溯，避免详细设计建立在缺失、过期或未确认输入之上。

## 2 适用阶段

SDS 编写启动后、正式详细设计展开前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| SDD 不存在 | 暂停 SDS，先补充或定位 SDD |
| SDD 未评审 | 说明风险，确认是否允许作为临时输入 |
| 关键设计项无定位 | 回到 SDD 修正，避免 SDS 无法追溯 |
| 规范未登记 | 补充 SDS 规范、模板、工作流和系统流程 |
| 输入版本不明 | 补充版本、日期或来源说明 |
| 关键输入缺失 | 登记开放项，判断是否阻塞 SDS |

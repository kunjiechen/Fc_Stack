# Gate 4 详细设计技术正确性检查清单

## 1 检查目标

确认 SDS 的设计语义、分支逻辑、错误处理、安全边界和并发策略技术上正确、清晰、可实施，不会在 Coding 阶段引入系统性返工。

## 2 适用阶段

SDS 内容完整后、进入通用化与下游可用性评审前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| 语义冲突 | 回写 SDD/SRS 或修正 SDS 语义 |
| 分支不闭环 | 补充边界、异常和恢复路径 |
| 错误/安全设计不可实现 | 补充或回写上游设计 |
| 并发策略不清 | 明确共享对象与保护方式 |
| 追溯错误 | 修正 SDS ID、来源或下游映射 |

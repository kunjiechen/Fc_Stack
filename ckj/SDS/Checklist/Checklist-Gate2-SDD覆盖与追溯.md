# Gate 2 SDD覆盖与追溯检查清单

## 1 检查目标

确认 SDS 已完整承接上游 SDD 设计输入，并建立清晰的 SDD → SDS 追溯关系，避免关键架构设计在详细设计阶段丢失、误解或被静默改变。

## 2 适用阶段

SDS 初稿完成后、技术完整性评审前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| SDD 项未覆盖 | 补充 SDS 设计项或登记不适用原因 |
| 追溯断裂 | 补充 SDD → SDS 追溯矩阵 |
| SDS 静默扩展设计 | 回写 SDD 或删除无来源设计 |
| N/A 无说明 | 补充 N/A 理由和影响分析 |

# Gate 1 架构输入完整性检查清单

## 1 检查目标

确认 SDD 编写所需输入已完整收集、适用性明确、版本和章节可追溯，避免架构设计建立在缺失、过期或未确认输入之上。

## 2 适用阶段

SDD 编写启动后、正式架构设计展开前。

## 4 不通过处理

| 问题类型 | 处理要求 |
| --- | --- |
| SRS 不存在 | 暂停 SDD，先补充或定位 SRS |
| SRS 未评审 | 说明风险，确认是否允许作为临时输入 |
| SRS ID 缺失 | 回到 SRS 修正，避免 SDD 无法追溯 |
| 规范未登记 | 补充 SDD 规范、模板、系统流程和文档标准 |
| 输入版本不明 | 补充版本、日期或来源说明 |
| 关键输入缺失 | 登记开放项，判断是否阻塞 SDD |

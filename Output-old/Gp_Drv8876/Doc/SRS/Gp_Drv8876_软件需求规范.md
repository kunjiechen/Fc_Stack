## 4 概述

本章仅保留理解需求所需的芯片和驱动背景信息，避免展开实现细节；正式软件责任以下文需求条目为准。

### 4.1 外设芯片介绍

DRV8876 是 TI 的 N 沟道 H 桥刷式直流电机驱动器，工作电压范围为 4.5V 至 37V，支持最高 3.5A 峰值输出电流，提供集成电流检测、电流调节、比例电流输出、休眠模式和 nFAULT 故障指示。芯片输入控制模式由 PMODE 引脚选择，电流调节和过流响应由 IMODE 引脚选择，PMODE 和 IMODE 在 nSLEEP 使能后锁存。

芯片支持以下功能：

- PH/EN、PWM 和独立半桥三种控制模式。
- Sleep、Hi-Z/Coast、Brake、Forward、Reverse 等 H 桥输出状态。
- IPROPI 比例电流输出，比例因数典型值为 1000 uA/A。
- VREF 与 RIPROPI 组合设置电流调节跳闸点。
- nFAULT 开漏故障指示，低电平表示 UVLO、CPUV、OCP、TSD 或逐周期电流斩波指示。
- nSLEEP 低电平进入低功耗睡眠，nSLEEP 高电平唤醒并进入活动模式。

### 4.2 驱动功能介绍

`Gp_Drv8876` 驱动应实现以下软件功能：

- 初始化每个已配置 DRV8876 实例的控制、诊断和反馈资源。
- 通过配置选择芯片控制模式和电流调节模式。
- 提供芯片模式设置和读取接口。
- 提供 H 桥输出控制接口，支持项目配置允许的输出状态。
- 提供故障状态读取接口，解释 nFAULT 低有效语义。
- 提供 IPROPI 电流反馈读取接口，支持外部 ADC 获取负载电流相关原始值或换算值。
- 对未初始化、无效 ID、无效参数、空指针和配置错误进行开发错误检测。

### 4.3 外设引脚介绍

| 引脚 | 方向 | Pin口功能 |
| --- | --- | --- |
| nSLEEP | 输入 | 睡眠控制输入；软件通过配置的 DIO 输出控制，低电平进入低功耗睡眠，高电平启用器件。 |
| EN/IN1 | 输入 | H 桥控制输入；在 PH/EN 模式下作为 EN，在 PWM/独立半桥模式下作为 IN1。 |
| PH/IN2 | 输入 | H 桥控制输入；在 PH/EN 模式下作为 PH，在 PWM/独立半桥模式下作为 IN2。 |
| PMODE | 输入 | 三电平控制模式选择输入；由硬件连接或软件控制资源决定，nSLEEP 使能后锁存。 |
| IMODE | 输入 | 四电平电流调节和过流响应选择输入；由硬件连接或软件控制资源决定，nSLEEP 使能后锁存。 |
| nFAULT | 输出 | 开漏故障指示输出；软件通过配置的 DIO 输入采样，低电平表示故障或逐周期电流斩波指示。 |
| IPROPI | 输出 | 比例电流模拟输出；软件通过配置的 ADC 通道采样。 |
| VREF | 输入 | 电流限制基准电压；由硬件或项目指定的 DAC/PWM/固定电压提供。 |
| OUT1/OUT2 | 输出 | H 桥功率输出，连接电机或负载；不由软件直接采样。 |
| VM/GND/PGND/VCP/CPH/CPL | 电源/电荷泵 | 电源、接地和电荷泵相关引脚；软件不直接控制。 |

### 4.4 状态机介绍

`Gp_Drv8876` 对外状态以软件请求和诊断状态为主，不保证仅通过软件即可确认芯片内部物理状态。模块应区分未初始化、初始化完成、活动控制、睡眠和故障状态。

| 状态 | 说明 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| Uninit | 模块未初始化 | 复位后或初始化前 | `Gp_Drv8876_Init` 成功完成 |
| Init | 已加载配置并置位默认输出 | 初始化流程完成 | 首次有效模式或输出请求 |
| Active | nSLEEP 高电平且模块允许输出控制 | 有效唤醒或输出控制请求 | Sleep 请求、配置错误或故障处理策略触发 |
| Sleep | nSLEEP 低电平，H 桥高阻态 | Sleep 模式请求或初始化默认策略配置为 Sleep | Wake/Active 请求且等待 tWAKE 后 |
| Fault | 软件检测到 nFAULT 有效或内部错误 | 故障采样有效、配置错误或接口错误 | 故障清除、重新初始化或项目定义恢复策略 |

## 5 功能需求

本章描述模块必须实现的功能行为，包括模式与状态、接口、配置、诊断和错误处理。每条需求使用固定字段描述，以便后续生成设计、测试和追溯矩阵。

### 5.1 模式需求

#### SRS-GPDRV8876-FUNC-0001 初始化默认状态控制

`功能需求` `QM` `Test / UT/IT` `Draft` `来源: 原始需求-驱动名称与安全级别；Datasheet-5 引脚功能；Datasheet-7.4 器件功能模式`

`Gp_Drv8876` 模块应在初始化时加载当前核可访问的 DRV8876 实例配置，并将每个实例的控制输出置为配置定义的默认安全状态。

**功能约束**

- **范围边界**：默认安全状态可配置为 Sleep、Coast 或 Brake；具体默认值需项目确认。
- **前置条件**：MCU DIO/PWM/ADC 资源已完成上游初始化；配置数据可访问。
- **触发条件**：上层调用 `Gp_Drv8876_Init(void)`。
- **输入**：每核实例配置、控制引脚配置、默认模式配置、默认输出配置。
- **输出**：nSLEEP、EN/IN1、PH/IN2、PMODE/IMODE 控制资源状态和实例软件状态。
- **异常处理**：配置缺失、实例数量越界或硬件资源无效时，应记录配置错误并禁止对对应实例下发输出控制。
- **验收准则**：每个有效配置实例初始化后处于定义的默认状态；无效配置实例不会产生未定义的 H 桥驱动输出。

#### SRS-GPDRV8876-FUNC-0002 Sleep 与 Active 模式切换

`功能需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-7.4.1 活动模式；Datasheet-7.4.2 低功耗睡眠模式；Datasheet-6.5 tWAKE/tSLEEP`

`Gp_Drv8876` 模块应支持通过 nSLEEP 控制每个已配置实例在 Sleep 和 Active 软件模式之间切换。

**功能约束**

- **范围边界**：Sleep 模式下 H 桥为高阻态；Active 表示器件已被软件请求启用，不表示物理故障均已消失。
- **前置条件**：模块已初始化；目标实例有效。
- **触发条件**：上层请求目标芯片模式为 Sleep 或 Active。
- **输入**：实例 ID、目标模式。
- **输出**：nSLEEP 控制输出和实例软件模式状态。
- **异常处理**：未初始化、实例 ID 无效或目标模式非法时，应拒绝切换并保持原控制输出不变。
- **验收准则**：Sleep 请求使 nSLEEP 输出低电平；Active 请求使 nSLEEP 输出高电平；非法请求不改变原状态。

#### SRS-GPDRV8876-FUNC-0003 H 桥输出状态控制

`功能需求` `QM` `Test / UT/IT` `Draft` `来源: Datasheet-7.3.2 控制模式；Datasheet-表3 PH/EN 控制模式；Datasheet-表4 PWM 控制模式`

`Gp_Drv8876` 模块应支持对已配置 H 桥实例请求 Coast、Brake、Forward 和 Reverse 输出状态，并根据已配置控制模式映射到 EN/IN1 与 PH/IN2 控制输出。

**功能约束**

- **范围边界**：项目是否同时支持 PH/EN 和 PWM 两种 H 桥控制模式需确认；独立半桥模式的对外接口见独立需求。
- **前置条件**：模块已初始化；实例处于 Active 软件模式；控制模式配置有效。
- **触发条件**：上层调用 H 桥输出设置接口。
- **输入**：实例 ID、目标输出状态、PWM 周期/占空比或等效输出控制参数。
- **输出**：EN/IN1、PH/IN2 对应控制输出和实例输出请求状态。
- **异常处理**：无效状态、无效占空比、无效实例或 Sleep 状态下的驱动请求应返回错误，并保持原输出请求状态不变。
- **验收准则**：在 PH/EN 模式和 PWM 模式下，Forward、Reverse、Brake、Coast 请求均映射到数据手册真值表定义的控制输出。

#### SRS-GPDRV8876-FUNC-0004 独立半桥输出控制边界

`功能需求` `QM` `Test / UT/IT` `Open Issue` `来源: Datasheet-7.3.2.3 独立半桥控制模式`

当项目配置启用独立半桥控制模式时，`Gp_Drv8876` 模块应支持对 OUT1 和 OUT2 对应半桥分别请求低侧导通和高侧导通输出状态。

**功能约束**

- **范围边界**：独立半桥模式会禁用内部电流调节；项目是否启用该模式需确认。
- **前置条件**：PMODE 配置为高阻态并在 nSLEEP 使能后锁存；模块已初始化。
- **触发条件**：上层调用半桥输出设置接口。
- **输入**：实例 ID、半桥通道 ID、目标半桥输出状态。
- **输出**：IN1 或 IN2 控制输出和半桥软件请求状态。
- **异常处理**：在非独立半桥模式下收到半桥级输出请求时，应拒绝请求并保持 H 桥输出状态不变。
- **验收准则**：INx=0 时对应 OUTx 低侧导通；INx=1 时对应 OUTx 高侧导通；模式不匹配请求被拒绝。

#### SRS-GPDRV8876-FUNC-0005 模式锁存处理

`功能需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-7.3.2 控制模式；Datasheet-7.3.3.2 电流调节`

`Gp_Drv8876` 模块应在需要改变 PMODE 或 IMODE 锁存状态时，先请求 nSLEEP 低电平并等待 tSLEEP，再更新 PMODE/IMODE 输入，随后请求 nSLEEP 高电平并等待 tWAKE 后允许输出控制。

**功能约束**

- **范围边界**：仅当 PMODE/IMODE 引脚由软件可控资源连接时适用；若由硬件固定连接，则软件应将其作为只读配置约束。
- **前置条件**：模块已初始化；目标实例有效；PMODE/IMODE 资源所有权属于本模块。
- **触发条件**：上层请求变更控制模式或电流调节模式。
- **输入**：实例 ID、目标 PMODE、目标 IMODE。
- **输出**：nSLEEP、PMODE、IMODE 控制输出和实例锁存配置状态。
- **异常处理**：PMODE/IMODE 硬件固定或配置为不可运行时变更，应拒绝请求并保持原锁存配置状态。
- **验收准则**：模式重锁存序列满足先 Sleep、改配置、再 Active 的顺序；未满足时序前不允许下发 H 桥输出控制。

### 5.2 接口需求

#### SRS-GPDRV8876-INTF-0001 初始化接口

`接口需求` `QM` `Test / UT` `Ready` `来源: 原始需求-驱动名称；AURIX2G 平台规范-Init 接口模式`

`Gp_Drv8876` 模块应提供 `void Gp_Drv8876_Init(void)` 接口，用于初始化当前核可访问的全部 DRV8876 实例。

**接口约束**

- **范围边界**：接口不接收运行时配置指针；配置由集成生成的配置数据提供。
- **前置条件**：MCAL DIO/PWM/ADC 初始化已完成。
- **触发条件**：系统启动或模块重新初始化流程调用。
- **输出**：模块初始化状态、实例默认控制输出、内部错误状态。
- **异常处理**：重复初始化应按项目约定重新加载配置或保持幂等；具体策略需设计阶段确认。
- **验收准则**：调用后可访问有效实例接口；无效配置实例被标记为不可用。

#### SRS-GPDRV8876-INTF-0002 芯片模式设置接口

`接口需求` `QM` `Test / UT/IT` `Draft` `来源: Datasheet-7.4 器件功能模式；AURIX2G 平台规范-SetDevModeOutSig`

`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_SetDevModeOutSig(uint16 Id_u16, uint8 DevMode_u8)` 接口，用于请求目标实例进入 Sleep 或 Active 软件模式。

**接口约束**

- **范围边界**：接口的 Active 模式不表示芯片无故障，仅表示 nSLEEP 被请求为启用状态。
- **前置条件**：模块已初始化；`Id_u16` 可映射到当前核有效实例。
- **触发条件**：上层请求改变芯片使能状态。
- **输入**：`Id_u16`、`DevMode_u8`。
- **输出**：`E_OK` 或 `E_NOT_OK`、nSLEEP 控制输出、实例软件模式状态。
- **异常处理**：未初始化、ID 无效、跨核访问或模式值非法时返回 `E_NOT_OK` 并保持原控制输出不变。
- **验收准则**：有效 Sleep/Active 请求返回 `E_OK` 并更新 nSLEEP；非法请求返回 `E_NOT_OK` 且不改变状态。

#### SRS-GPDRV8876-INTF-0003 芯片模式读取接口

`接口需求` `QM` `Test / UT` `Ready` `来源: AURIX2G 平台规范-GetDevModeInSig；Datasheet-7.4 器件功能模式`

`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_GetDevModeInSig(uint16 Id_u16, uint8 *DevMode_pu8)` 接口，用于读取目标实例最新被接受的软件模式请求状态。

**接口约束**

- **范围边界**：该接口返回软件请求状态，不声明物理确认模式。
- **前置条件**：模块已初始化；输出指针非空。
- **触发条件**：上层查询芯片模式。
- **输入**：`Id_u16`、`DevMode_pu8`。
- **输出**：`E_OK` 或 `E_NOT_OK`、软件模式值。
- **异常处理**：未初始化、ID 无效、跨核访问或空指针时返回 `E_NOT_OK`，不写入输出参数。
- **验收准则**：成功返回值与最近一次被接受的模式请求一致；失败场景不修改输出参数。

#### SRS-GPDRV8876-INTF-0004 H 桥输出设置接口

`接口需求` `QM` `Test / UT/IT` `Draft` `来源: Datasheet-表3 PH/EN 控制模式；Datasheet-表4 PWM 控制模式；AURIX2G 平台规范-SetOutput`

`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_SetHbOutSig(uint16 Id_u16, uint8 HbState_u8, uint32 Period_u32, uint32 Duty_u32)` 接口，用于设置目标实例的 H 桥输出状态和 PWM 参数。

**接口约束**

- **范围边界**：`Period_u32` 与 `Duty_u32` 的单位、范围和空闲电平需项目配置确认。
- **前置条件**：模块已初始化；目标实例处于 Active 软件模式；控制模式支持 H 桥控制。
- **触发条件**：上层请求改变电机输出状态。
- **输入**：`Id_u16`、`HbState_u8`、`Period_u32`、`Duty_u32`。
- **输出**：`E_OK` 或 `E_NOT_OK`、EN/IN1 与 PH/IN2 控制输出。
- **异常处理**：参数非法、占空比大于周期、实例无效、Sleep 状态或配置不支持当前状态时返回 `E_NOT_OK` 并保持原输出请求状态。
- **验收准则**：有效输出请求映射至数据手册真值表；非法请求不改变既有输出控制。

#### SRS-GPDRV8876-INTF-0005 半桥输出设置接口

`接口需求` `QM` `Test / UT/IT` `Open Issue` `来源: Datasheet-表5 独立半桥控制模式；AURIX2G 平台规范-SetOutput`

当项目启用独立半桥控制模式时，`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_SetHalfBridgeOutSig(uint16 Id_u16, uint8 HalfBridge_u8, uint8 OutState_u8)` 接口，用于单独设置 OUT1 或 OUT2 对应半桥输出状态。

**接口约束**

- **范围边界**：若项目不启用独立半桥模式，该接口可不交付或固定返回 `E_NOT_OK`。
- **前置条件**：模块已初始化；实例配置为独立半桥模式。
- **触发条件**：上层请求单半桥输出。
- **输入**：`Id_u16`、`HalfBridge_u8`、`OutState_u8`。
- **输出**：`E_OK` 或 `E_NOT_OK`、对应 INx 控制输出。
- **异常处理**：模式不匹配、半桥 ID 无效或输出状态非法时返回 `E_NOT_OK` 并保持原状态。
- **验收准则**：启用独立半桥时，OUT1/OUT2 可分别按请求进入低侧或高侧导通；禁用时请求被拒绝。

#### SRS-GPDRV8876-INTF-0006 故障读取接口

`接口需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-5 引脚功能 nFAULT；Datasheet-7.3.4 保护电路；AURIX2G 平台规范-GetDevFaultSig`

`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_GetDevFaultSig(uint16 Id_u16, uint32 *Fault_pu32)` 接口，用于读取并返回目标实例的软件故障状态位掩码。

**接口约束**

- **范围边界**：nFAULT 为低有效聚合故障指示；若没有额外硬件测量，软件不能区分 UVLO、CPUV、OCP、TSD 的具体物理根因。
- **前置条件**：模块已初始化；输出指针非空；nFAULT DIO 通道配置有效。
- **触发条件**：上层查询故障状态。
- **输入**：`Id_u16`、`Fault_pu32`。
- **输出**：`E_OK` 或 `E_NOT_OK`、故障位掩码。
- **异常处理**：未初始化、ID 无效、跨核访问或空指针时返回 `E_NOT_OK`，不写入输出参数。
- **验收准则**：nFAULT 采样为低时返回故障有效位；nFAULT 采样为高时返回无芯片故障位；接口错误返回定义错误。

#### SRS-GPDRV8876-INTF-0007 电流反馈读取接口

`接口需求` `QM` `Test / UT/IT` `Draft` `来源: Datasheet-7.3.3.1 电流检测；Datasheet-公式1/2；AURIX2G 平台规范-GetRaw`

`Gp_Drv8876` 模块应提供 `Std_ReturnType Gp_Drv8876_GetCurrentRaw(uint16 Id_u16, uint16 *Raw_pu16)` 或项目等效接口，用于读取目标实例 IPROPI 对应 ADC 原始值。

**接口约束**

- **范围边界**：该接口读取软件可见 ADC 原始值；是否在驱动内换算为电流值需项目确认。
- **前置条件**：模块已初始化；输出指针非空；IPROPI ADC 通道配置有效。
- **触发条件**：上层请求读取负载电流反馈。
- **输入**：`Id_u16`、`Raw_pu16`。
- **输出**：`E_OK` 或 `E_NOT_OK`、ADC 原始值。
- **异常处理**：ADC 通道不可用、未初始化、ID 无效或空指针时返回 `E_NOT_OK`，不写入输出参数。
- **验收准则**：有效请求返回对应实例 IPROPI ADC 原始值；接口错误不修改输出参数。

### 5.3 配置需求

#### SRS-GPDRV8876-CFG-0001 实例与信号映射配置

`配置需求` `QM` `Review/Test / Review/UT` `Draft` `来源: AURIX2G 平台规范-信号 ID 设计规范；Datasheet-5 引脚配置和功能`

`Gp_Drv8876` 模块应支持通过配置将 `uint16 Id` 映射到 Core ID、芯片实例索引、H 桥或半桥通道索引以及对应 MCU 硬件资源。

**配置约束**

- **范围边界**：每个 ID 只能映射到一个有效实例或通道；多核访问按 Core ID 约束。
- **输入**：实例数量、Core ID、Chip Index、Channel Index、nSLEEP/EN/PH/nFAULT/IPROPI 资源 ID。
- **输出**：接口调用时的实例解析结果。
- **异常处理**：配置重复、跨核映射或资源缺失时，应使对应 ID 不可用并触发开发错误检测。
- **验收准则**：有效 ID 可解析到唯一资源；无效、重复或跨核 ID 被拒绝。

#### SRS-GPDRV8876-CFG-0002 控制模式配置

`配置需求` `QM` `Review/Test / Review/UT` `Ready` `来源: Datasheet-表2 PMODE 功能；Datasheet-7.3.2 控制模式`

`Gp_Drv8876` 模块应为每个实例配置 PMODE 控制模式，取值范围为 PH/EN、PWM 或独立半桥。

**配置约束**

- **范围边界**：PMODE 低电平对应 PH/EN，高电平对应 PWM，高阻态对应独立半桥。
- **输入**：实例 PMODE 配置枚举和 PMODE 引脚控制方式。
- **输出**：输出设置接口的真值表选择。
- **异常处理**：PMODE 枚举非法或 PMODE 资源不可用时，对应实例不得进入 Active 输出控制。
- **验收准则**：每个有效实例使用其 PMODE 配置选择唯一控制模式；非法配置被检测。

#### SRS-GPDRV8876-CFG-0003 电流调节模式配置

`配置需求` `QM` `Review/Test / Review/UT` `Ready` `来源: Datasheet-表6 IMODE 功能；Datasheet-7.3.3.2 电流调节`

`Gp_Drv8876` 模块应为每个实例配置 IMODE 电流调节和过流响应模式，取值范围为四电平 1、四电平 2、四电平 3、四电平 4。

**配置约束**

- **范围边界**：四电平 1/4 为固定关断时间电流斩波，四电平 2/3 为逐周期电流斩波；过流响应按数据手册自动重试或输出锁存语义执行。
- **输入**：实例 IMODE 配置枚举和 IMODE 引脚控制方式。
- **输出**：模式锁存序列与诊断解释边界。
- **异常处理**：IMODE 配置非法时，对应实例不得进入 Active 输出控制。
- **验收准则**：每个有效实例使用唯一 IMODE 配置；非法配置被检测。

#### SRS-GPDRV8876-CFG-0004 PWM 参数配置

`配置需求` `QM` `Review/Test / Review/UT` `Draft` `来源: Datasheet-6.3 建议运行条件 fPWM；AURIX2G 平台规范-MCU PWM 输出`

`Gp_Drv8876` 模块应支持为每个 H 桥输出通道配置 PWM 资源、周期单位、周期范围、占空比范围和空闲输出状态。

**配置约束**

- **范围边界**：DRV8876 输入 PWM 频率建议运行范围为 0..100 kHz；项目应定义软件接口使用的时间单位。
- **输入**：PWM 通道 ID、周期最小值、周期最大值、占空比范围、空闲状态。
- **输出**：H 桥输出设置接口的参数校验边界。
- **异常处理**：PWM 配置缺失或参数范围非法时，对应输出接口应返回 `E_NOT_OK`。
- **验收准则**：周期和占空比边界可通过配置审查和接口边界测试验证。

#### SRS-GPDRV8876-CFG-0005 电流反馈配置

`配置需求` `QM` `Review/Test / Review/UT` `Draft` `来源: Datasheet-7.3.3.1 电流检测；Datasheet-公式1/2/3`

`Gp_Drv8876` 模块应支持为每个实例配置 IPROPI ADC 通道、RIPROPI 电阻值、AIPROPI 比例因数和 VREF 参考电压参数。

**配置约束**

- **范围边界**：AIPROPI 典型值为 1000 uA/A；实际误差与校准策略需项目确认。
- **输入**：ADC 通道、RIPROPI、AIPROPI、VREF、ADC 基准电压。
- **输出**：电流反馈读取和电流换算的配置依据。
- **异常处理**：配置缺失或数值为 0 导致不可换算时，应禁止电流换算并返回错误或仅返回原始值。
- **验收准则**：配置可支持按 `V_IPROPI = I_PROPI * R_IPROPI` 和 `I_TRIP * AIPROPI = VREF / RIPROPI` 进行审查。

### 5.4 诊断需求

#### SRS-GPDRV8876-DIAG-0001 开发错误检测

`诊断需求` `QM` `Test / UT` `Ready` `来源: AURIX2G 平台规范-诊断错误码设计；SRS 构建规则-DET 要求`

`Gp_Drv8876` 模块应提供开发错误检测能力，对未初始化访问、空指针、非法参数、无效 ID、跨核访问和配置错误进行检测，并按项目约定进行 DET 上报或错误返回。

**诊断约束**

- **范围边界**：若项目未集成 DET 模块，也应保留等效错误返回语义。
- **触发条件**：外部接口被调用且前置条件不满足。
- **输出**：DET 事件或 `E_NOT_OK` 返回值，内部错误标志。
- **异常处理**：错误场景下应拒绝继续执行当前请求，并保持无关状态不被破坏。
- **验收准则**：通过接口边界测试验证所有开发错误均可被检测且不会导致输出误动作。

#### SRS-GPDRV8876-DIAG-0002 nFAULT 低有效语义

`诊断需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-5 引脚功能 nFAULT；Datasheet-7.3.4 保护电路；Datasheet-表7 故障条件汇总`

`Gp_Drv8876` 模块应将 nFAULT 输入低电平解释为芯片故障或逐周期电流斩波指示有效，并将 nFAULT 高电平解释为未检测到该聚合故障指示。

**诊断约束**

- **范围边界**：仅凭 nFAULT 不能区分 UVLO、CPUV、OCP、TSD 的具体故障源。
- **前置条件**：nFAULT DIO 通道配置有效。
- **触发条件**：故障读取接口采样 nFAULT。
- **输入**：nFAULT DIO 输入电平。
- **输出**：故障位掩码。
- **异常处理**：DIO 读取失败时应返回接口错误，不得报告为无故障。
- **验收准则**：nFAULT 低电平产生故障有效位；nFAULT 高电平清除聚合故障位。

#### SRS-GPDRV8876-DIAG-0003 逐周期电流斩波指示边界

`诊断需求` `QM` `Review/Test / UT/IT` `Draft` `来源: Datasheet-7.3.3.2.2 逐周期电流斩波；Datasheet-表6 IMODE 功能`

当实例配置为逐周期电流斩波且 nFAULT 在前进或后退控制请求期间被拉低时，`Gp_Drv8876` 模块应能够将该状态作为电流斩波指示或聚合故障候选报告给上层。

**诊断约束**

- **范围边界**：是否区分电流斩波指示与真实故障需项目确认；若不区分，应报告为聚合故障。
- **前置条件**：IMODE 为逐周期模式；当前输出请求为 Forward 或 Reverse。
- **触发条件**：nFAULT 被采样为低电平。
- **输入**：IMODE 配置、当前输出请求、nFAULT 电平。
- **输出**：故障位或电流斩波指示位。
- **异常处理**：控制请求为 Hi-Z 或 Brake 时 nFAULT 低电平应按芯片故障候选处理。
- **验收准则**：逐周期模式下可依据当前控制请求区分或保守报告 nFAULT 低电平。

#### SRS-GPDRV8876-DIAG-0004 过流响应软件边界

`诊断需求` `QM` `Review/Test / UT/IT` `Ready` `来源: Datasheet-7.3.4.3 OUT 过流保护；Datasheet-表6 IMODE 功能`

`Gp_Drv8876` 模块应在需求和接口语义中保留 DRV8876 过流响应边界：自动重试或输出锁存由 IMODE 硬件配置决定，软件不得声明替代芯片内部 OCP 保护。

**诊断约束**

- **范围边界**：软件可读取 nFAULT 并执行项目定义的降级策略；OCP 限流、禁用 MOSFET 和重试计时由芯片内部执行。
- **触发条件**：配置审查、故障读取或故障处理策略评审。
- **输入**：IMODE 配置、nFAULT 状态。
- **输出**：软件故障状态和上层可见的诊断信息。
- **异常处理**：锁存型 OCP 需由 nSLEEP 重置或 VM 断电恢复，软件不得仅通过清除内部变量声明故障恢复。
- **验收准则**：需求、设计和测试均能区分芯片内部保护与软件诊断责任。

### 6.1 时序需求

#### SRS-GPDRV8876-TIM-0001 Sleep 进入等待时间

`时序需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-6.5 tSLEEP`

`Gp_Drv8876` 模块应在将 nSLEEP 从高电平切换为低电平后，等待不小于 1 ms 或由项目配置给出的更大值，再认为实例进入 Sleep 软件完成状态。

**时序约束**

- **触发条件**：Sleep 模式请求被接受并驱动 nSLEEP 低电平。
- **输入**：tSLEEP 配置值，最小值为 1 ms。
- **输出**：Sleep 软件完成状态。
- **异常处理**：等待完成前收到输出驱动请求时，应拒绝或延后处理，具体策略需设计明确。
- **验收准则**：测试或分析证明 nSLEEP 拉低后至少经过 1 ms 才允许依赖 Sleep 完成的后续动作。

#### SRS-GPDRV8876-TIM-0002 Active 唤醒等待时间

`时序需求` `QM` `Test / UT/IT` `Ready` `来源: Datasheet-6.5 tWAKE`

`Gp_Drv8876` 模块应在将 nSLEEP 从低电平切换为高电平后，等待不小于 1 ms 或由项目配置给出的更大值，再允许对该实例下发 H 桥输出控制。

**时序约束**

- **触发条件**：Active 模式请求被接受并驱动 nSLEEP 高电平。
- **输入**：tWAKE 配置值，最小值为 1 ms。
- **输出**：输出控制允许状态。
- **异常处理**：等待完成前的输出控制请求应返回 `E_NOT_OK` 或进入项目定义的 pending 策略。
- **验收准则**：测试或分析证明唤醒等待完成前不会产生有效 H 桥输出驱动。

#### SRS-GPDRV8876-TIM-0003 PWM 输入频率边界

`时序需求` `QM` `Review/Test / UT/IT` `Ready` `来源: Datasheet-6.3 建议运行条件 fPWM`

`Gp_Drv8876` 模块应校验或通过配置约束保证 EN/IN1、PH/IN2 输入 PWM 频率不超过 100 kHz。

**时序约束**

- **范围边界**：当 PWM 由上游模块直接配置且本模块不持有周期参数时，本模块应在配置审查中声明该边界。
- **输入**：PWM 周期或频率配置。
- **输出**：参数校验结果或配置审查结论。
- **异常处理**：频率超过 100 kHz 的运行时请求应返回 `E_NOT_OK`；配置阶段发现越界应禁止生成有效实例。
- **验收准则**：配置审查或边界测试覆盖 100 kHz 上限。
